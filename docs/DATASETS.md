# Datasets

## Clearance → coverage pathways *(in development)*

A separate, hand-verified dataset — **not yet part of the main monitor** — tracks how AI-enabled devices move from authorisation to reimbursement across major markets.

It is intentionally conservative: entries are added only when dates can be verified from primary sources, and both successful and unsuccessful outcomes (coverage, refusals, delistings) are retained to keep the record unbiased.

This is an early, secondary component. The daily evidence monitor remains the flagship. Definitions for coverage status live in [TAXONOMY.md](../TAXONOMY.md) — because "covered" is not one thing (a Category III CPT code, a provisional DiGA listing and a time-limited NTAP are not equivalent).
